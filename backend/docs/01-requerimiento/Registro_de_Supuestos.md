Este documento es la **fuente única** de todo lo que la documentación da por cierto **sin que el cliente lo haya confirmado**. Cada supuesto tiene una propuesta concreta (para poder construir sin quedar parados), la evidencia en que se apoya, la alternativa y el impacto si el cliente decide otra cosa.

> **Regla de uso.** Cualquier documento que dependa de un supuesto lo cita como **⚠ SUP-xx**. Las decisiones puramente técnicas (que valida el equipo, no el cliente) se citan como **⚙ DT-xx**. Cuando el cliente confirme o cambie un supuesto, se actualiza **aquí primero** (estado + fecha + quién) y luego cada documento que lo cita (buscar `SUP-xx`).

**Estados:** `⚠ PROPUESTO` (no confirmado, se construye así) · `✅ CONFIRMADO` (pasa a decisión cerrada del SRS §9.1) · `✏ CAMBIADO` (el cliente eligió otra opción; ver nota).
